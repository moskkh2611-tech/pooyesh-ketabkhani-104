# پویش کتابخوانی نسخه ۱.۰.۱ موبایل

این نسخه از پویش کتابخوانی با رابط واکنش‌گرا برای موبایل به‌روزرسانی شده است.

### تغییرات
- هنگام چرخاندن گوشی از عمودی به افقی و بالعکس، چیدمان خودکار تغییر می‌کند.
- در افقی، فضای صفحه بهتر استفاده شده، فرم و فهرست کتاب‌ها کنار هم قرار می‌گیرند و آمار در یک ردیف نمایش داده می‌شود.
- در عمودی، چیدمان تک‌ستونی و نوار پایین موبایل به حالت مناسب برمی‌گردد.
- در تنظیمات ظاهر، مدیر می‌تواند صفحه ورود و درخواست رمز را خاموش/روشن کند.

### امنیت حالت بدون رمز
اگر فعال شود، برنامه به‌صورت خودکار با حساب مدیر فعال باز می‌شود. این قابلیت برای گوشی شخصی یا دستگاهی که دیگران به آن دسترسی ندارند مناسب است؛ در محیط مشترک توصیه نمی‌شود.

### نصب و ساخت APK
راهنمای کامل در `BUILD_APK.md` قرار دارد. این بسته شامل سورس و فایل‌های آماده Capacitor است؛ APK نهایی هنوز کامپایل نشده.

نسخه ۱.۰.۲: فیلد اختیاری اهداکننده افزوده شد؛ جستجو، جزئیات و خروجی‌ها از نام اهداکننده پشتیبانی می‌کنند.


نسخه ۱.۰.۳: مشخصات تکمیلی امانت‌گیرنده (شماره تماس، شماره پشتیبان و آیدی شبکه اجتماعی) افزوده شد؛ همه اختیاری و قابل جستجو هستند.


## ساخت APK بدون Android Studio

این مخزن فایل GitHub Actions را در `.github/workflows/build-apk.yml` دارد. پس از بارگذاری فایل‌ها در ریشه مخزن و Commit، از تب Actions اجرای Build APK را باز کنید. بعد از موفقیت، در بخش Artifacts فایل `app-debug.apk` قابل دانلود است.


نسخه ۱.۰.۴: انتخاب چند رده سنی به‌صورت هم‌زمان و نمایش فیلد اختیاری سن عددی پس از انتخاب «سایر».
